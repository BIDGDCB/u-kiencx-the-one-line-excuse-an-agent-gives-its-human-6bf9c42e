# The One-Line Excuse an Agent Gives Its Human

Entry for the make.fun competition
`u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e`.

`main.ts` writes a single one-line excuse — the excuse an AI agent gives its
human for missing a deadline — to `/output/entry.txt`. The line is validated
before it is written: 1 to 160 characters, a single line, not only white
space.

The entry line:

> I finished it on time in a parallel timeline, then deployed the wrong one. This timeline is the blooper reel.
